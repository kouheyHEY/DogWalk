# Spec — コンテンツ改善（A〜E ＋ ジャンプ音）

## 目的 / なぜ
育成の芯を太くする。プレイヤーに「目的」と「世話の手応え（失敗）」を与え、成長とアクションに
見せ場と緊張感を足す。決定事項はユーザー確認済み（2026-06-18）。

---

## A. 目的の可視化
- 育成画面に「次の節目」を1行表示。
- AC:
  - [ ] 体重 < 25kg のとき「あと X.Xkg で てんせい」を表示。
  - [ ] 体重 ≥ 25kg のとき「てんせい できる！」を表示。
  - [ ] 空腹メーター（下記B）を上部ステータスにバー表示。

## B. 空腹メーター ＋「永遠の眠り」
- 新ステータス `hunger`（0=満腹 〜 100=限界）。時間経過で増加、ごはんで減少。
- 数値（初期案・要確認）:
  - 増加 `HUNGER_PER_MIN = 0.05`/ゲーム内分（満腹→限界 約1.4日 ≒ 実33分放置で限界）。
  - ごはんで `-40`（clamp 0）。睡眠ジャンプ中も経過分ぶん増える。
- 「永遠の眠り」: `hunger >= 100` で発動。
  - その生命をリセット: `weight=5 / days=1 / food=8 / hunger=0 / gameMinutes=8:00 /
    isSleeping=false / lastWokeAt=null / recentUnlocks=[]`。
  - 引き継ぐ（メタ）: `name / achievements / totalFeedCount / totalSleepCount / reincarnationCount`。
  - 画面はタイトルへ。タイトルに「○○は 永遠の眠りについた…」を一度だけ表示。
- 眠気はメーター化せず、既存の「ねる」クールダウン表示で代替（死因は空腹のみ）。
- AC:
  - [ ] 放置で hunger が増え、満腹で減る。バー表示が追従。
  - [ ] hunger=100 で永遠の眠り→リセット＆メタ引き継ぎ→タイトルに死亡メッセージ。
  - [ ] アクション中に限界でも正しくタイトルへ。

## C. アクションの難化（成長対応）
- **穴幅を体重スケールで拡大**: `gapScale = clamp(baseScale/0.5, 1, 4)` を GAP_MIN/MAX に乗算
  （体重5→等倍, 10→2倍, 20→4倍で頭打ち）。大きくなっても落ちられるように。
- **宙のブロック（障害物）**: 一定間隔で空中に出現し左へスクロール。キャラが触れたら
  アクション終了（穴落ちと同じく育成へ戻る）。初期案: 2.5〜5秒間隔・1辺28px・
  地面から 40〜120px の高さ。
- AC:
  - [ ] 体重が増えるほど穴が広い。
  - [ ] 宙ブロックに触れると育成画面へ戻る。
  - [ ] 既存の「拾うとごはん＋1」「穴落ちで戻る」は維持。

## D. 節目の演出
- 体重 10kg / 25kg 到達、転生、称号獲得で中央に演出（2秒・専用SE「ファンファーレ」）。
- 実績トーストとは別レイヤーの「祝い演出」。
- AC:
  - [ ] 10kg/25kg を初めて跨いだ瞬間に演出＋SE。
  - [ ] 転生・称号獲得でも演出。

## E. 称号（転生5回ごと）
- `reincarnationCount` が 5 の倍数に達するごとに新しい称号を獲得。
- 称号名（初期案・**要確認**）: 5「みならいのぬし」/ 10「いちにんまえのぬし」/
  15「ベテランのぬし」/ 20「めいじんのぬし」/ 25「でんせつのぬし」/ それ以降は「でんせつのぬし★n」。
- 表示: タイトル画面の名前の下＋ハンバーガーメニュー。獲得時はDの演出。
- AC:
  - [ ] 転生回数が5の倍数になると称号が更新される。
  - [ ] 現在の称号がタイトル/メニューに表示。

## F. ジャンプ効果音
- アクションのジャンプ時に短いSEを鳴らす（`jump`）。
- AC: [ ] ジャンプのたびに音が鳴る。

## スコープ / 非対象
- In: 上記 A〜F。
- Out（今回外）: 眠気の独立メーター、歩きアニメ、アクションのスコア表示、新背景の追加（既存3テーマ流用）。

## 進め方
小さく分けて実装→各段でテスト（純粋ロジックは vitest）。最後にまとめて1PR・本番反映は別途指示で。
